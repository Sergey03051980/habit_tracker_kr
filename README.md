# Habit Tracker Backend

Бэкенд для трекера полезных привычек на основе книги "Атомные привычки" Джеймса Клира.

## 🚀 Технологии

- **Python 3.9+**
- **Django 4.2** - веб-фреймворк
- **Django REST Framework** - API
- **PostgreSQL** - база данных
- **Celery + Redis** - асинхронные задачи
- **Telegram Bot API** - уведомления
- **JWT** - аутентификация
- **Poetry** - управление зависимостями
- **Docker** - контейнеризация

## 📋 Функциональность

### Модели
- Пользователи с Telegram интеграцией
- Привычки (полезные и приятные)
- Валидация привычек (не более 120 секунд, периодичность 1-7 дней)

### API Эндпоинты
- ✅ Регистрация и авторизация (JWT)
- ✅ CRUD для привычек
- ✅ Публичные привычки
- ✅ Пагинация (5 привычек на страницу)
- ✅ Валидация привычек

### Интеграции
- ✅ Telegram бот для напоминаний
- ✅ Celery задачи для отложенных уведомлений
- ✅ CORS для работы с фронтендом
