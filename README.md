## 📖 Описание проекта

Проект реализует систему управления привычками, позволяющую пользователям:
- Создавать и отслеживать полезные привычки
- Получать напоминания через Telegram
- Анализировать прогресс выполнения
- Обмениваться публичными привычками с другими пользователями

Основан на принципах книги "Атомные привычки" Джеймса Клира.

## 🚀 Функциональность

### Основные возможности:
- ✅ **Регистрация и аутентификация** пользователей (JWT)
- ✅ **CRUD операции** для привычек
- ✅ **Публичные привычки** - общий доступ для вдохновения
- ✅ **Отметка выполнения** привычек
- ✅ **Валидация** по бизнес-правилам
- ✅ **Пагинация** списков (5 элементов на страницу)
- ✅ **Телеграм-бот** для напоминаний
- ✅ **Отложенные задачи** через Celery
- ✅ **CORS** для работы с фронтендом
- ✅ **Документация API** (Swagger/ReDoc)

### Бизнес-правила (валидация):
1. Время выполнения привычки ≤ 120 секунд
2. Периодичность выполнения: 1-7 дней
3. Нельзя одновременно указывать связанную привычку и вознаграждение
4. Связанная привычка должна быть "приятной"
5. У приятной привычки не может быть вознаграждения или связанной привычки
6. Полезная привычка должна иметь либо вознаграждение, либо связанную привычку

- JWT аутентификация
- DRF Spectacular (документация)

**Интеграции:**
- Telegram Bot API
- CORS headers

**Инструменты разработки:**
- Poetry (управление зависимостями)
- Flake8 (линтер)
- Coverage.py (покрытие тестами)
- Pytest
